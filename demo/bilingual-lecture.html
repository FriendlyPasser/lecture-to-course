Which denominator should we use?

Using the entire club includes members who do not meet the given condition. Which words in the question restrict the group?

Use 10: only chess players belong to the reference group. The answer is 4/10.

Using 40 instead gives the share of the entire club doing both activities, which answers a different question.

Underlying rule · page 2

We can now count 4 out of 10. But if a report gives only probabilities, how can we recover that same answer? Turn the club counts into the conditional probability formula.

How can probabilities recover the same answer?

  • Recover 4/10 from probability shares and explain why the conditioning probability must be positive.

The club exercise gave 4/10 by counting within the chess group. Keep the same group while rewriting both counts as shares of all 40 members.

Let C mean playing chess and T mean playing tennis. The club counts stay fixed: P(C) = 10/40 and P(T ∩ C) = 4/40.

P(T | C) = P(T ∩ C) / P(C) = (4/40) / (10/40) = 4/10 = 40%.

The common total of 40 cancels. The formula rescales the share doing both activities to the chess group.

This formula requires P(C) > 0. Here 10/40 is positive; if nobody played chess, this ratio would be undefined.

Underlying rule · page 2

Return to the source survey: (24/100) / (40/100) = 24/40 = 60%. The same rule explains the source example and our new club case.
