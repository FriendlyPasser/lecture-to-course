# Local browser compatibility

Keep the course file-compatible and offline. Do not diagnose all local-file failures as a universal Chrome limitation: opening context and browser permissions can differ. When a user reports blocked companion files, use the generated loopback launcher rather than asking them to disable browser security or move files into privileged locations.

The builder includes `launch_course.py` (Python 3 standard library only) and executable `打开课程.command` (macOS double-click entry). The launcher serves only the course directory on `127.0.0.1`, chooses an available port, prints the URL, and opens the default browser. It does not publish online. Do not hardcode a port, user path, or browser into generated launchers. If the user requests Chrome explicitly, open the printed URL in Chrome. The launcher window must remain open; Control+C or closing it stops access. Relaunching may produce a different URL. On other platforms, run `python3 launch_course.py` using the available Python 3 command.

Validate each built artifact’s launcher with `python3 launch_course.py --no-browser`. Verify that the printed URL and actual lecture HTML, CSS, JS, selected images, and source PDFs return successfully. Check quiz and glossary interactions over HTTP when addressing a browser-opening failure. Verify direct file mode separately when available. External network access can be disabled while allowing loopback; a browser’s global offline emulation may block loopback too. Do not claim a localhost HTTP test passes under that mode unless it actually does. Stop test servers afterwards; keep a user-facing server running if it was started for immediate use.

Deliver the course index plus the macOS launcher link, noting that the launcher is the fallback if direct opening fails. When already serving, give the actual printed URL and explain how to reopen later. A local launcher is compatible with offline study but requires Python 3; verify the runtime rather than assuming every Mac includes it. Do not claim the issue is fixed from static checks alone.
